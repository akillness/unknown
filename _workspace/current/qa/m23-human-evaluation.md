# M23 · 사람 평가 실행 패킷과 측정 경계

**실제 참가자 n=0. H-1/H-2/H-3와 조위정합 개념 검증은 미측정이다.** 이 문서는 모집·동의·플레이·회고 결과가 아니며 Base를 승인하지 않는다. 정본은 `handoff/verification-plan.md` §1과 `production/premium-preproduction-contract.md`의 Base production gate다.

## 동결과 두 표본의 격리

- 빌드·소스·데이터 지문과 실제 실행 증거는 `systems/tech-verification/m23/verification.json` 및 동 폴더 실행 영수증을 사용한다. 소스 변경 뒤에는 이전 참가자와 새 빌드의 값을 한 회차로 합치지 않는다.
- **정식 T0 초회:** 기존 세이브가 없는 전용 로컬 폴더를 `--t0-save-dir`로 지정. `--m23-alignment-practice`를 넣지 않는다. 연습장·공략·스포일러를 본 사람은 이 12명에 들어가지 않는다. 접근성 요구 유형을 포함한 5유형, 최소12명이며 중복 유형 계상 금지.
- **별도 조위정합 파일럿/전이:** 같은 빌드를 `--m23-alignment-practice`로 실행할 수 있다. 인자·노출 순서를 지문 옆에 기록. 이 표본은 정식 초회 표본과 별도이며 코딩 에이전트의 입력 재생도 사람 표본이 아니다.
- 네이티브 개발 검증의 `fixture-reader`/`fixture-signature`는 실제 명령을 재생한 **개발 전용 체크포인트**다. 사람 초회 폴더로 복사하지 않는다.
- 이름·계정·IP·장치 식별자·키 입력 내용은 수집하지 않는다. 동의 후 UUID 세션 ID만 사용. 원본 영상/자유 답변은 로컬의 Git 제외 경로에 보관하며 원격 전송·모집·게시를 이 작업이 승인하지 않는다.

## 실제 수집기 부재와 수동 관찰 경로

현재 게임은 정본 §1.5의 연구 이벤트 전체를 JSONL로 출력하지 않는다. 자동저장 명령 로그와 힌트 유휴 타이머는 그 수집기의 대체물이 아니다. `first_valid_action` 또는 `afk_gap` 자동 이벤트가 생겼다고 보고하지 않는다.

수동 H-1/H-2/H-3 관찰에는 **실제 게임 창 한 개만 녹화한 타임코드 영상 + 관측자 기록 + 참가자 회고**를 사용한다. 네이티브 녹화 기능의 실행 여부/해상도/길이는 M23 실행 영수증으로 확인한다. 녹화가 실패하면 전체 데스크톱·마이크로 자동 확대하지 않고 측정 준비 미완료로 둔다. 코딩 검증용 짧은 영상만으로 45분 세션의 안정성을 주장하지 않는다.

관측 원본 한 행에는 `session_id, build_fingerprint, launch_arguments, video_time_sec, event, before, after, evidence_frame, observer, certainty`를 남긴다. 확인할 수 없는 이벤트·시점·입력은 `unknown`/`null`이며 추정 횟수를 실측으로 채우지 않는다. 영상과 관측으로 얻지 못한 §1.5의 전체 키는 계속 **미수집**이다. 이 수동 경로를 전체 텔레메트리 구현 완료로 부르지 않는다.

### H-1 동결 정의

시작점은 시작 버튼을 포함한 **첫 인터랙티브 게임 프레임**이다. 도입 안내 시간을 뒤로 옮겨 성적을 개선하지 않는다. 끝점은 T0 퍼즐의 첫 수락된 작업(예: 인수 문서의 처음 읽은 행/줄 체크가 실제로 바뀜)이다. 시작/스킵/설정/포커스 이동만으로 성공 처리하지 않는다. UI 상태 변화가 확인되지 않는 눌림도 수락으로 세지 않는다. 두 타임코드의 차이를 초 단위로 기록하고 12명의 중앙값과 개인 분포를 함께 보고한다. 판정선은 기존 ≤60초다.

### H-2/H-3·이탈

기존 자유 회상 절차와 질문을 유지한다. 두 관측자가 독립 채점하며 불일치는 `부분`으로 내린다. 설명 가능 최소10/12가 기준이다. 힌트3단 이후15분 무진전 또는 진행을 위한 관측자 개입은 막힘으로 기록하며 0/12만 통과한다. 45분 상한, 미완주·중단 이유·개입 원문을 보존한다. 관측하지 못한 힌트3단 시점으로 시간을 역산하지 않는다.

### AFK

60초 이상 입력이 관측되지 않은 구간은 **후보**일 뿐이다. 마우스 이동·스크롤·패널 열기도 입력이며, 창 영상만으로 보이지 않는 키 입력의 부재를 단정하지 않는다. 관측 불확실성을 기록하고 즉시 회고에서 `away | thinking | unknown`을 원본 구간과 연결한다. `away`만 제외하며 생각/불명은 남긴다. 회고가 없으면 `afk_total_min=null`, `total_minus_afk_min=null`; 유효 판정 표본에서 제외하고 **미회고**로 별도 보고한다. 미완주와 미회고는 서로 다른 열이다.

## 조위정합 개념 검증 질문

정답 유도 없이 참가자가 앵커 대응·기준선·잔차를 설명하고, 접함/겹침에서 순서를 확정하지 않는지 관찰한다. 제안 버튼이 적용/잠금을 대신하지 않는지, 수동 선택 후 잠금하는지, 낯선 전이 시편에서 같은 규칙을 사용하는지 본다. 단순 구간 순서를 인과 확정으로 설명하는지도 기록한다. 기본 시편과 전이의 응답/행동은 별도로 남긴다. 자동 테스트의 수학적 통과는 이 이해 결과가 아니다.

## 현재 차단과 다음 책임

- QA/운영: 실제 동의된12명/5유형, 두 관측자, 초회 노출 확인, 로컬 원본과 AFK 회고가 필요하다. 현재 모두 실제 세션 결과 없음.
- Systems/QA: 정본 전체 연구 이벤트가 필요한 회차 전에 동의 기반 로컬 수집기를 구현·검증하거나 정본 소유자와 수집 방법을 명시적으로 개정해야 한다. 수동으로 확인 불가능한 키를 템플릿의0으로 채우지 않는다.
- Director: 최초 T0 견적 대비 실제 작업 소요를 취합하고150% STOP을 적용한다. 세션 경과 시간이나 Git 파일 날짜를 사람 작업 시간으로 바꾸지 않는다.

# RFC-CX-010 — 기사 적용 범위 결정

[OBSERVED] 사용자 지정 WeChat 글을 제작자와 별도 검토 담당이 각각 공개 HTTP로 읽었다. 연출 담당은 제작자의 원문 요약과 세계관/GDD/M7 문서를 대조했다. 아래는 이 세션에서 실제 교환한 의견의 요약이다.

- 연출: ‘검토 노트’로 명명. 플레이어의 미확정 메모를 보존하고 확인 가능한 출처 관계만 요약한다. 정답·확신도·확정 가능 배지와 미공개 자료 추천은 제외한다. 입력 없이도 완주 가능해야 한다.
- 원문 검토: MIMESIS는 실제 당회차 음성을 맥락적으로 재사용한 사례다. 과거의 대화·의도 복원은 이 게임의 기록 범위와 충돌한다. 기사 수치는 독립 검증한 시장 자료가 아니다.
- 시스템: 별도 로컬 메모 저장과 선택적 UI를 연결한다. 기존 게임 저널·Sim·C1 판정·자원은 유지한다. 텍스트 입력 중 게임 단축키가 실행되지 않는 경계를 시험한다.
- 디렉터: 위 범위로 구현한다. 신규 네트워크/모델 호출과 생성 자산을 추가하지 않는다. 저장 파일 식별, 손상/미래 버전 보호, 실패 시 초안 보존을 포함한다. 원천/매체 구분은 실제 데이터 필드만 사용하고 불명확한 관계를 추측하지 않는다.

[TARGET] 원문이 제시하는 자유 표현·문맥 유지의 가치를 제한된 오프라인 기능으로 시험한다. 재미·몰입의 향상과 AI의 자연어 이해를 검증했다는 주장은 하지 않는다. 네이티브 자동화 검증은 별도 영수증으로 남긴다.

# M7 컨셉 우선 연출 JSON 메타데이터

[TARGET] `concept-first-m7.json`은 세계관/아트 지침과 원본 컨셉4장만으로 후속 영화를 설계한다. 새 GTI 광학 작업대는 원본 판독기+당직실에서만 파생한다. 이미지4장의 직접 시각 검사·해시/크기를 기록했으며 구현에서 파생된 입력은 사용하지 않는다.

[TARGET] 실행 목표는 동일 모델4×6초,시네마틱24초·방법32초다. 초기8초 샷 안은 `originalProposal`에 이전 목표로 보존한다. 신규 대조링 제안은 철회했으며 기존 크랭크·확대경·광학판으로 관찰·가역 시험을 표현한다. 물리 동작이 실패하면 카메라 컷과 설명용 도해로 바꾸고 실제 조작 성공을 주장하지 않는다.

[OBSERVED] 견적/잔액은 제작자 전달값이며 이 담당의 제공자 집행0건·코드/runtime 적용0건이다. 생성 파일과 실제 비용은 후속 제작 영수증이 기록한다. 몰입4는 목표이며 인간 검증이 아니다. `runtimeEligible:false`, `commercialReleaseEligible:false`를 유지한다.


## 초기 생성 실측·채택

[OBSERVED] 새 M7클립4개의contact sheet를 검사했다. 모두141프레임/24fps/5.875초/무음이며 S1/S2는1364×768, S3/S4는1152×768이다.6초 편집은 마지막0.125초 홀드로 맞춘다. S1공간·S3기록 맥락·S4닫힌 수문은 채택할 수 있다. S3에서 카드 정리/기록 완료 동작은 관찰되지 않았다.

[OBSERVED] S2손은 매끈한 블록형 형태가 세밀한 판독기 재질과 어긋나 수정1회를 권고했다. 초기 손을 최종 아트 목표나 자원 참조에 사용하지 않는다. 수정 및 최종 편집 판정은 `systems/tech-verification/concept-first-m7/art-review.json`이 갱신한다. 기존샷 ms·카메라 수치는 저작 목표로 보존한다.


[OBSERVED · S2수정 채택] r02는 피부·손가락·직물 소매의 질감이 개선돼 재질/연출 방향으로 채택했다. r1손은 제외한다. 해부·리깅·크랭크 연결/정확한 복원은 미검증이며, 최종 합성 판정은 art-review에 별도로 기록한다.


## 최종 실행 결과

[OBSERVED] 최종 시네마틱24초/576프레임,방법32초/768프레임,1280×720/24fps를 독립 해시·ffprobe와 편집 표본으로 확인했다. 실제 두 편은 S1→S2r02→S3→S4각6초이며 방법 영화 끝24–32초에 미래 플레이 설명 카드가 추가된다. 원래 도해 분산 배치는 이 실제 편집으로 대체됐다. 파일 해시·원본 계보·최종 판정은 `systems/tech-verification/concept-first-m7/art-review.json`의 `finalFilms`와 `finalExecution`이다.

[OBSERVED] S2r1손은 제외하고 r02재질을 채택했다. S3는 기록 맥락의 카메라 장면이며 실제 기록 완료를 증명하지 않는다. S4는 닫힌 문/다음 장소 맥락이다. S1에 일부 측면 얼굴이 보이는 편차는 공간/몸 연출용으로만 채택한다. 주요 자막과 상단 미래목표 표기가 최종 프레임에 들어오고 S3/S4상단 크롭은 주요 구조/수평선을 보존한다.

[OBSERVED] 현재 판정은 범위를 한정한 아트/편집 표본 PASS다. 해부·리깅·정확한 크랭크 연결/복원·종이/판 생성무늬의 증거 의미·청취·인간 몰입·runtime적용·상업 승격은 미검증으로 남긴다. 원본4장과 GTI파생의 입력 계보 및 해시는 확인했으며 현재runtime시각 자료를 입력으로 사용하지 않았다.

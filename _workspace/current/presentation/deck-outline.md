## 1. 약속 (이 덱을 다 본 사람이 알아야 하는 것)
1. 이 게임은 **아직 존재하지 않는다**. 빌드 0건, 사람 플레이 n=0, 성능 NOT-MEASURED.
2. 480분은 **설계 예산**이지 관측 완주 시간이 아니다.
3. Steam 등록 행위는 **0건**이고, 가격 3안은 **전부 미승인**이다.
4. 정책 수치만 1차 출처가 있고 나머지는 가정이다. 배분율 70/30은 **가정이며 사실이 아니다**.

## 2. 표기 규칙
- `[관측]` 이 머신 또는 공식 문서에서 직접 확인한 것.
- `[목표]` 설계 목표. 달성 증거 아님.
- `[가정]` 근거 없는 입력값. 감도 분석에만 쓴다.
- `[미확인]` 확인 창구는 있으나 확인하지 못한 것.
- 이모지와 em dash를 쓰지 않는다. 슬라이드 본문은 최대 6줄.
- **가격 표에는 기준 라벨을 붙인다 (C5-F8)**: 23번 표는 `표시가(부가세 10% 포함) · 할인 <DISC> 적용` 기준이고, `product/business-model.md` 5절 표는 `할인 0% · 정가` 기준이다. 두 표는 같은 이름(`B2 본당 수취`)에 다른 값을 갖는 것이 정상이며, 덱은 본문 1줄 + 표 머리 + 노트에서 세 번 기준을 밝힌다. **덱은 `business-model.md` 를 고치지 않는다** — 5절 표 머리의 라벨은 product 레인 소유다.
- **폐기 용어 금지**: 「매체」+「경로」를 이어 쓴 세 번째 용어는 `systems/unity-implementation.md` L69 가 명시적으로 폐기했다. 빌드가 렌더 결과에서 이 문자열을 찾으면 실패한다.

## 5. 빌드
```
node _workspace/current/presentation/generate-deck.mjs --out <절대경로.html> [--out <절대경로2.html>]
```
- 모듈은 `import.meta.url` 기준으로 원본을 찾으므로 **어느 cwd에서 실행해도** 동작한다.
- 사용자 경로를 코드에 넣지 않는다. 출력 경로는 CLI 인자로만 받는다.
- 외부 의존성 없음(Node 내장 `fs`, `path`, `url`만 사용). 네트워크 접근 없음.
- 빌드 시 자체 점검: 슬라이드 36장, 본문 6줄 이하, 이모지/em dash 0건, 각 슬라이드 노트 3항목 존재, 출처 링크 존재.

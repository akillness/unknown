# C1 M4 — 겹쳐 붙은 서명지 연출 패킷

## 범위와 근거

[OBSERVED] 정본은 `planning/campaign.json`의 `c1-b2` 및 `synopsis/chapter-beats.md`의 같은 id다. 선행은 `c1-b1`, 장소는 당직실(`hub`), 도구는 판독(`reader`)이다. 소금에 붙은 두 장을 분리하고 각각 사본으로 보존한 뒤 판 #0의 번호대를 대조한다. 두 번째 서명란 아래는 계속 미해결이다. 13분은 저작 추정이며 플레이 실측이 아니다.

[OBSERVED] 기존 자료 확인: `concept/style-guide.md`·`worldview/glossary.md`, `concept/prompts/tool-reader-hero.txt`, `animation/anim-list.md`, `vfx/vfx-budget.md`, `vfx/vfx-spec.md`, `motion/motion-contract.md`. `vfx/effect-library.md`는 현재 없으며 기존 여섯 효과 목록은 `vfx-budget.md`에 있다. 판독기 컨셉은 재사용하고 별도 일곱 번째 도구를 만들지 않는다.

[OBSERVED] 눈으로 확인한 기반은 `docs/media/t0-gameplay-capture-20260910.jpg`의 어두운 좌측 관찰 영역·우측 기록 UI와 `systems/tech-verification/c1-m3/panel/panel-front.png`의 마모된 청회 금속·낮은 기계 구조다. 전자는 T0 캡처이며 M4 결과가 아니다. 후자는 정적 계통판 진단 캡처이며 움직이는 계기나 실제 분기 상태를 증명하지 않는다.

[TARGET] 이 패킷은 C1 M4 한 비트의 P3 저작 기준이다. 신규 리소스 생성·임포트·실기 캡처·몰입 평가를 통과했다는 뜻이 아니다. 제작 대상과 프롬프트는 `concept/c1-signature-art-brief.md`에 있다. [OBSERVED · director ACK] RFC-CX-005가 정적 판독대·빈 종이 표면·0 ms 상태 컷을 승인했다.

## 의도와 연출 시간

느낌: **붙은 두 장이 따로 보존되어도, 가려진 한 부분은 끝내 남아 있다.** 화려한 발견보다 조심스러운 절차의 진전을 느끼게 한다. 카메라는 기존 고정 관찰점과 UI 영역을 유지한다. 새 카메라 팬·줌·흔들림·컷신·깜빡임은 0이다.

아래 시간은 모두 [TARGET]이며 관측값이 아니다. `0 ms`는 해당 상태가 권위 있는 스냅샷으로 전달된 다음 첫 표시 프레임에서 정적으로 바뀐다는 뜻이다. 저장·입력 지연을 0 ms로 측정했다는 뜻이 아니다. 이번 범위는 상태 컷만 저작한다. 기존 `plate_insert` 250 ms, `gauge_settle` 400 ms, `stamp_down` 300 ms 클립을 구현했다고 주장하지 않는다.

## 상태별 시각 계약

| 상태 | 그림에 표시 | 행동 뒤 드러나는 정보 | 계속 가릴 정보 |

| 진입 / 미관찰 | 판독기·얕은 습도판 받침, 가장자리가 붙은 두 장 | 자료를 조사할 수 있다는 중립적인 조작 문구 | 적정 습도 단수, 독립 출처 판정, 판 #0 대역 연결, 서명 이름 |

| 저장 성공 | 저장된 결론과 미해결 영역을 정적으로 유지 | 체크포인트 및 두 출처 연결 결과 | c1-b3 자동 완료, c4-b2의 이름 복원 |

**두 소금 층은 분리한다.** 가장자리 접착층은 분리 상태만 표현한다. 둘째 장 하단 소금 그늘은 별도 불투명 마스크로 모든 M4 상태에서 유지한다. 마스크 아래에 나중 장의 이름이나 글리프를 숨겨 렌더하지 않는다. 이번 데이터와 텍스처에 그 글자를 넣지 않는다.

가려진 영역의 증거 좌표는 시스템의 저작 데이터에서 읽고 UI가 문장으로 표시한다. [OBSERVED · planner/director ACK] 승인 주석은 종이 좌상단 기준 정규화 `(x: 0.12, y: 0.70, width: 0.76, height: 0.22)`이며 물리 실측이 아니다. 그림의 장식 마스크 위치를 역산해서 증거 좌표를 만들지 않는다. 사본 두 장은 `signature-annex` 하나의 출처를 상속하며 비교되는 독립 매체는 `plate-zero`다. 내부 id는 디버그 데이터이고 기본 플레이 UI에 노출할 문구가 아니다.

## 레이아웃·접근성

[TARGET] 기존 좌측 관찰 / 우측 기록 UI의 역할을 유지한다. 좌측에는 낮은 판독대 실루엣을, 우측에는 실제 상호작용과 자료 읽기를 둔다. 판독기 관찰 영역 배경은 심해 잉크 `#0E1F26`로 맞추고 기본 Unity 하늘과 지평선을 표시하지 않는다. 두 사본을 동시에 읽을 수 없는 폭에서는 세로 카드와 탭으로 전환한다. 관찰 그림의 작은 글자로 퍼즐을 풀게 하지 않는다.

- 서명지 면 내부 여백은 짧은 변의 8% 이상, 기록문 뒤의 종이 질감은 저대비. 종이 회백 `#E7E3D8` 위 확정 잉크 `#173238`을 사용한다. 상태는 텍스트·윤곽·배치로 구별한다.
- 150% 본문 배율에서 컨테이너를 늘리고 줄바꿈·스크롤을 허용한다. 축소 글꼴이나 잘림으로 한 화면에 맞추지 않는다. 기본 상태에서 답이나 출처가 선공개되는 툴팁도 금지한다.
- 키보드 초점 순서는 관찰 → 조건 선택 → 시험 → 분리 → 각 사본 → 자료 대조 → 확정의 현재 가능한 순서다. 탭과 뒤로가기는 항상 보이고, 그림이 입력을 가로채지 않는다.
- 저감모션은 동일한 정적 상태와 문장을 사용한다. 표시 애니메이션을 기다리는 타이머나 모션 전용 단서는 없다. 효과·오디오·생성 리소스가 빠져도 동일한 자료와 행동을 읽을 수 있다.
- UI 라벨은 한국어 문자열 테이블에서 렌더한다. 이미지에 글자·숫자·서명·출처를 굽지 않는다. 습도는 시스템이 소유한 단수만 표시하며 단위·백분율·정답 힌트를 새로 발명하지 않는다.

## 시스템 연계 불변식

Presentation은 현재 스냅샷과 현재 유효 영수증을 **읽기만** 한다. 페이지를 펼치는 연출 종료, 이미지 로드 완료, 애니메이션 이벤트, 소금 픽셀 수, 카메라 가시 여부는 분리·사본·대조·체크포인트 조건이 아니다. 실패한 시험은 반복 가능하고 원본 소모를 나타내지 않는다. 저장 실패·중복·오래된 콜백·재로드에서 성공 연출은 새로 발생하지 않는다. 이번 패킷의 정적 확정 표시는 저장된 결과만 표현한다.

## QA 인수와 영향 패스

다음은 실행 전 인수 기준이며 PASS 기록이 아니다. QA가 실제 빌드와 캡처 경로를 붙여 결과를 별도 기록한다.

| 항목 | 필요한 전후 증거 |
|---|---|
| 일관성 | 기존 M3 panel/T0 화면과 새 판독대의 같은 팔레트·둥근 판독기 실루엣·마모 금속 비교 |
| 진입 스포일러 | 신규 세이브 c1-b2 진입 캡처에 정답 단수·미관찰 출처 문장·대역 일치·후속 이름이 없음 |
| 분리 차이 | 동일 프레이밍의 겹친 상태와 분리 상태; 가장자리만 바뀌고 하단 가림은 동일 |

| 저장 경계 | 지연·실패·재시도에서 완료 표시는 성공 영수증 뒤에만 발생 |
| 150% / 저감모션 | 최대 글꼴·저감모션으로 모든 본문·버튼·힌트·미해결 영역을 읽고 끝까지 조작 |

G4 사람 몰입, G5 GPU/메모리 성능, 전체 C1 플레이시간은 이 문서로 측정하지 않는다. 리소스가 예산을 넘으면 장식 메시·맵·중복 종이를 줄이고 같은 읽기 계약을 유지한다.

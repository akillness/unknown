# M5 실제 생성 영상 검수와 런타임 채택 경계

[OBSERVED] 이 문서는 생성된 영상의 **프레임 표본**을 직접 읽은 결과다. 플레이어 입력을 녹화한 게임플레이가 아니며, 실제 런타임 구현·G4 몰입·G5 성능 검증도 아니다. 영상의 실제 프롬프트는 각 폴더 `prompt.txt`이며 `intro-gameplay-m5.json`의 저작 목표와 다를 수 있다. 실제 발생한 차이를 목표에 맞춰 다시 적지 않는다.

## 소스 스틸

- [OBSERVED] `assets/generated/2d/concept/intro-m5-r03/image.png`: 빈 남색 장부 표지, 판독 가능한 문자 없는 전화 다이얼, 빈 트레이. 인물 이름·수치·결손 도표·C1 판독기·서명지·완료 암시는 보이지 않았다. **내부 프로토타입 인트로 참고용 시각 통과**. r01/r02는 문자형 표지/다이얼 정리 전 원본으로 보존한다. 수평선은 화면 높이 약 25%로, 스타일 가이드 목표 38–44%와 구도 편차가 있다.
- [OBSERVED] `assets/generated/2d/concept/c1-playflow-m5-r01/image.png`: 연결된 원형 판독기, 겹친 빈 종이, 하단 소금 얼룩, 별도 빈 카드, 우측 여백. **C1 프리비즈 참고용 시각 통과**. 소금 그릇/병/핀셋과 육각 소금 트레이는 추가 장식이며 실제 염판 매체나 도구로 승격하지 않는다.
- [TARGET] 내부 프로토타입 적용과 상업 배포 권리 판정은 구별한다. 위 시각 판정은 제공자 이용 경로의 지원 여부, 산출물 권리, 상업 배포를 승인하지 않는다. 해당 판정은 디렉터의 별도 rights-review/decision-log가 소유한다.

## C1 플레이 방식 프리비즈 — 실제 파일

- [OBSERVED] 파일: `assets/generated/previz/intro-gameplay-m5/gameplay/clip.mp4`
- [OBSERVED] ffprobe: H.264, **1280×720**, **24 fps**, **6.041667초**, **2,186,119 bytes**, 영상 스트림 1개, 오디오 스트림 없음. 요청 6초와 실제 길이의 차이는 그대로 기록한다.
- [OBSERVED] 검수한 표본: 폴더의 `contact-sheet.png`, 그리고 원본 프레임 `n = 0, 12, 24, …, 132`를 추출한 0.0~5.5초의 0.5초 간격 **12프레임**. 임시 비교판은 `/tmp/unknown-m5-gameplay-review-half-second.png`이며 배포 증거로 약속하지 않는다.
- [OBSERVED] 컷 후보 측정: FFmpeg `select=gt(scene,0.20),showinfo`가 **2.083333초**, **4.041667초**를 검출했다. 샘플에서도 wide → 손잡이 확대 → wide 순서를 확인했다. 따라서 정확히 2.000/4.000초에 컷했다고 쓰지 않는다.

| 실제 시간 / 표본 | 관찰한 결과 | 채택 | 기각 / 구현 경계 |
|---|---|---|---|
| 0.0~2.0초 표본 | 판독기·겹친 종이·별도 빈 기록 카드가 한 구도에 있다 | 현재 관찰 대상, 조절 부위, 기록 자리를 시각적으로 분리하는 구성 | 장식 물체를 실제 도구·증거로 추가하지 않는다 |
| 2.083333초 컷, 2.5~4.0초 표본 | 손잡이와 종이 확대. 손잡이 각도가 바뀌고 확대 구도도 조금 이동한다 | 선택한 시험 제어가 무엇인지 정적 윤곽/라벨로 드러내는 아이디어 | 자동 손잡이 조작, 카메라 이동, 영상 각도를 실제 습도 값이나 가역성의 증명으로 쓰지 않는다 |
| 4.041667초 컷, 4.5~5.5초 표본 | 전체 구도로 복귀하며 빈 기록 카드가 오른쪽에 남는다. 종이 하단의 짙은 얼룩이 거의 사라져 더 깨끗해 보인다 | 기록 영역을 따로 두되 후보/저장 대기/실패/영수증 수락을 실제 상태로 구별하는 구성 | **자동 세척/가림 제거는 기각.** 이 클립은 하단 가림 유지 계약을 시각적으로 충족하지 않는다. 후반 종이 이미지를 실제 단서/마스크/성공 상태로 사용하지 않는다 |

[OBSERVED] 이 영상의 색·물성·좌우 배치는 참고할 수 있으나, **가림 유지와 완전 고정 시점의 모델 동작 재현에는 실패**했다. 원본을 수정하거나 폐기하지 않고, 이 실패를 포함한 **한계가 명시된 내부 연출 연구 프리비즈**로 보존한다. 손잡이가 원위치로 돌아오는지에 대한 연속 영상 검증은 이 프레임 표본만으로 완료하지 않았다. 의미 있는 임의 문자/인물 이름/값은 본 표본에서 보이지 않았다.

## 실제 플레이 적용으로 채택하는 규칙

[TARGET] 영상 자체를 퍼즐 시스템에 연결하지 않고, 아래 **정적 읽기 전용 방향표**로 변환한다. 영상의 컷 시간은 네이티브 진행 타이머가 아니다.

| 영상에서 배운 것 | 네이티브 구현 계약 | 불변식 |
|---|---|---|
| 관찰 대상이 먼저 읽히는 wide 구도 | 실제 선택한 자료의 제어 종류를 `관찰`로 표시하고 이미 공개된 상태만 읽는다 | 새 단서/값/관계 공개 없음 |
| 시험 부위가 한눈에 보이는 close 구도 | 실제 선택한 조건/시험 제어를 `시험`으로 표시; 현재 선택과 기존 시험 결과만 표시 | 입력은 플레이어가 명시적으로 실행; 자동 시험/정답 강조/초점 이동 없음 |
| 별도 기록 공간이 계속 보이는 wide 구도 | 사본/대조/확정 제어 선택은 `기록`; 현재 후보·대기·실패·수락 영수증 상태를 구별 | 저장 수락 전 성공 문구 없음; 시간/영상 완료로 상태 변경 없음 |
| 차분한 재질과 어두운 여백 | 인트로는 **hub r03만** 정적 배경 후보로 사용; C1 이미지와 영상은 초반 인트로에 넣지 않는다 | pre-t0-b1 공개 상한, 저감모션/150%/설정/즉시 건너뛰기 유지 |

[TARGET] 정확한 하단 미해결 마스크와 그 좌표는 기존 승인 C1 시스템/연출 계약을 사용한다. 생성 영상의 얼룩 픽셀·카메라 컷·손잡이 각도에서 게임 상태를 역산하지 않는다. 이 문서가 기존 마스크나 저장 영수증 계약을 덮어쓰지 않는다.

## 인트로 프리비즈 — 실제 파일과 채택

- [OBSERVED] 파일: `assets/generated/previz/intro-gameplay-m5/intro/clip.mp4`. ffprobe: H.264, **1280×720**, **24 fps**, **6.041667초**, **1,946,634 bytes**, 영상 스트림 1개, 오디오 없음.
- [OBSERVED] 검수: `intro/contact-sheet.png`와 프레임 `n = 0, 12, …, 132`, 즉 **0.0~5.5초 / 0.5초 간격 12프레임**. 임시 비교판 `/tmp/unknown-m5-intro-review-half-second.png`는 배포 증거로 약속하지 않는다.
- [OBSERVED] FFmpeg `select=gt(scene,0.20),showinfo` 컷 후보는 **3.125초**(24 fps 기준 75번 프레임). 표본도 3.0초까지 방 전체, 3.5초부터 책상 확대다. 목표 2.500초와 다르며 실제 2.500초 컷이라고 기록하지 않는다.

| 실제 시간 / 표본 | 관찰 | 채택 | 기각 |
|---|---|---|---|
| 0.0~3.0초 표본 | 빈 당직실, 어두운 우측 여백, 닫힌 남색 장부, 수화기, 빈 트레이 | 먼저 공간의 정서를 보고 다음에 작업대 맥락을 읽는 두 단계 구조, 깨끗한 hub r03의 정적 배경 | 생성 물결/비 움직임을 실제 수위 상태나 시간 단서로 해석하지 않음 |
| 3.125초 컷, 3.5~5.5초 표본 | 닫힌 남색 장부·램프·전화기를 가까이 보여준다. 트레이 안에 새 줄무늬 종이가 생겼고 다이얼에 작은 표시가 다시 생겼다 | 작업대에 책임과 주의를 모으는 두 번째 문맥; 별도 카메라 이동 없이 정적 캡션으로 표현 | **새 종이·줄무늬·다이얼 표시를 기각.** 원본 GTI hub r03에 없던 문서 내용을 캐논이나 런타임 자원으로 옮기지 않음 |

[OBSERVED] 인트로 표본에서 C1 판독기/서명지 모티프, 인물 이름, 네 시간 결손 도표, 퍼즐 완료는 보이지 않았다. 그러나 제공자가 두 번째 샷에 문서형 내용을 발명했으므로 **영상 자체/후반 컷을 네이티브 인트로 자산으로 임포트하지 않는다.** 무문자 원본 상태를 재현했다고도 주장하지 않는다.

[TARGET · 디렉터 적용 방향] 네이티브 인트로는 검수한 **깨끗한 GTI hub r03 하나만** 사용하고, 두 개의 정적인 캡션/문맥 단계로 바꾼다. 카메라 이동·동영상 재생·새 문서 삽입은 없다. [OBSERVED · 디렉터 판정] 영상에서 관측한 **3125 ms** 컷을 채택했다. 첫 캡션 3125 ms, 두 번째 2875 ms, 네이티브 합계 **6000 ms**다. 제공자 실제 영상 **6041.667 ms**와 다르며 원래 요청 2500 ms를 실제 관측으로 쓰지 않는다. 타이머와 캡션은 퍼즐/세이브에 쓰지 않는다.

## 영상 이후 GTI 리소스 도출

[OBSERVED] 실제 C1 closeup **2.5초** 프레임을 참고해 GTI가 `assets/generated/2d/ui/m5-direction-surface-r01/image.png`를 생성했다. 실제 **1254×1254**, SHA256 `52c4b3cc65cc1432bd94c5e7207ea35a50cbd5d8507f98e9c27f760db590b414`. 참조 프레임은 같은 폴더 `reference-frame.png`, SHA256 `b34fa327235ddb7a5eeae3ad15d9a575976cf45aef4de9f4519e618cec3f52d3`이며 실제 생성 프롬프트는 `prompt.txt`다. 이는 영상 이전 hub/source still과 구분되는 **영상 이후 새 리소스**다.

[OBSERVED · 직접 시각 검수] 중앙이 조용한 청흑/심해 잉크 표면이며 미세한 입자와 낮은 대비의 마모가 테두리에 모인다. 판독 가능한 문자·숫자·단서·손잡이·종이·가림 도형은 보이지 않았다. **C1 방향표 장식 표면의 내부 프로토타입 후보로 시각 통과**. 이 이미지는 영상의 금속 질감을 추출해 그대로 쓴 컷아웃이 아니라 GTI로 재생성한 표면이다.

[TARGET] 실제 적용은 방향표 배경 장식뿐이며 상태를 색/질감으로 단독 부호화하지 않는다. 텍스트 대비·150%·키보드 초점·영수증 상태는 네이티브 합성에서 검증한다. 이미지 시각 통과를 임포트·네이티브 인수·성능·상업적 권리 통과로 읽지 않는다. 런타임 provenance 승격은 디렉터가 별도로 기록한다.

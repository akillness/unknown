# M18 — C1 면접(대화) 준비 화면: 형식 안내 기초 계약

> **이 문서가 무엇인가**: C1 순찰을 끝낸 플레이어에게 *면접이라는 형식이 존재한다*는 사실만
> 보여주는 **표시 전용(display-only) UI 기초 한 조각**의 연출 계약이다.
> 정본 대화 비트(S2 / `c1-b4` 이후)의 구현이 **아니고**, 실제 대화 비트의 대체물도 **아니며**,
> 접근성 인증·사람 플레이테스트·성능 측정·네이티브 캡처 주장도 **아니다**.

같은 사이클 안의 제자리 추가다 (RFC-Q2: `cycle` 값 불변 → `supersedes: null`, 아카이브 의무 없음).

## 0. status: draft 인 이유 (게이트 규칙 준수)

`references/dependency-matrix.md`의 **presentation 행**은 `syn ● / vfx ● / anim ● / mot ● / mod ● / qa ●`
를 요구하고, 같은 문서가 "required acks가 없는 변경은 `status: draft`로 남고 게이트에 투입될 수 없다"
고 규정한다. 이번 세션에는 해당 레인의 독립 응답이 **없다**. CLAUDE.md §11은 가상의 동의를 만들지
말라고 규정하므로 ack를 자작하지 않고 `status: draft`로 남긴다.

- **미해결 ● ack**: synopsis, vfx, animation, motion, modeling, qa
- **RFC 블록 미작성 사유**: RFC는 `production/decision-log.md`에 기록되며 이 파일은 디렉터 소유
  공유 진실 산출물이다. 이번 작업 지시는 기존 공유 진실 산출물 편집을 금지했다. 또한 이 변경은
  새 캐논을 수립하지 않고(정본 노출은 아래 §2에서 전면 배제), 공유 진실 파일
  (`presentation/presentation-spec.md`, `worldview/glossary.md`, `planning/campaign.json`,
  `balance/balance-sheet.md`, `qa/gate-measurements.md`)을 하나도 건드리지 않는다.
  따라서 교차 레인 판정을 요구하는 실질 변경이 아니라 **신규 소유 산출물 + 표시 전용 코드**이며,
  matrix가 정한 대로 ack 없이는 draft에 머문다.
- 이 문서는 **어떤 게이트도 올리지 않는다**. G4는 `NOT-MEASURED`를 유지한다.

## 1. 플레이어 약속 (intended player promise)

[TARGET] 순찰을 끝낸 플레이어가 얻는 것은 **단 하나의 정보**다:
"다음 단계에는 두 사람의 진술을 나란히 놓고 같은 기준으로 비교하는 절차가 있다."

- 약속하는 것: 형식의 **존재**와 **모양**(두 레인 + 비교 기준 + 명시적 복귀).
- 약속하지 않는 것: 누가 말하는지, 무엇을 말하는지, 언제·얼마의 값인지, 어떻게 판정하는지.
- 감정 목표: 불안이나 긴장 고조가 아니라 **절차적 예고**. 플레이어는 이 화면에서 아무것도
  결정하지 않으며, 아무것도 잃지 않는다.
- `immersion_target`: 측정하지 않는다(N/A). 이 조각은 몰입 연출이 아니라 형식 고지다.

## 3. C1 게이트 (언제 보이는가)

- **가시 조건**: `PatrolComplete`(= `Simulation.IsComplete(state, c1-b1)`)가 참이고
  서명지 단계로 넘어가지 않은 **완료된 C1 순찰 화면**일 때만 진입 액션이 존재한다.
- 순찰 미완료 상태, 신규 저장, T0 기본 순찰/서명 화면에는 **액션 자체가 없다**.
- 진입은 **명시적 플레이어 입력 1회**로만 일어난다. 자동 팝업·타이머·전환 연출 없음.
- 기존 완료 화면의 두 액션(서명지철 이동, 자료 검토)은 그대로 남고 순서도 바뀌지 않는다.

## 6. 수용 기준 (자동 검사 가능한 형태)

1. 완료된 C1 순찰 화면에 진입 액션이 **존재하고 활성**이다.
2. 활성화하면 `Surface=="interviewPrep"`이고, 렌더된 텍스트에 **익명 화자 레인 2개**와
   **중립 비교 프롬프트**가 보인다.
3. 패널에 **명시적 복귀 액션**이 보인다.
4. 배제 목록 E1–E4가 §2의 검사 방법으로 통과한다.
5. 진입→복귀 전 구간에서 상태 해시·저널 head·`save.json` 바이트·영수증 수가 불변이다.
6. 복귀 후 다시 **완료된 C1 순찰 화면**이다(`PatrolComplete` 유지, 기존 액션 존재).

## 7. 비목표 (explicit non-goals)

1. 정본 `c1-b4` 이후 대화·심문 비트의 구현이 아니다. 실제 진술 내용은 이 조각에 없다.
2. 실제 대화 비트의 대체물·축약본이 아니다. 후속 비트는 이 화면을 전제하지 않는다.
3. 대화 시스템(분기, 신뢰도, 압박, 판정, 증거 제시)의 설계가 아니다. 상태 기계 0개.
4. 접근성 인증이 아니다. 기존 텍스트 배율·저감모션 설정을 그대로 상속만 한다.

7. 시놉시스·세계관 캐논 수립이 아니다. 새 고유명사 0건.

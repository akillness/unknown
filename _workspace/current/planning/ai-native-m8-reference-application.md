# M8 참고 적용 — 자유 가설과 근거 검토

[TARGET] M7의 원본 컨셉 기반 자원 방향 위에 **선택적인 검토 노트**를 추가한다. 플레이어가 자유롭게 가설을 쓰고 이미 확인한 출처를 연결하면, 연결 구조를 요약하고 다음 검증 질문 하나를 보여준다. 첫 구현은 저작된 규칙과 문장으로 작동하며 AI 모델·네트워크 추론을 추가하지 않는다. M7와 기존 세계관/GDD를 대체하지 않는다.

## 외부 사례에서 가져올 것

[REFERENCE] 사용자 제공 [罗斯基 기사](https://mp.weixin.qq.com/s/YmqCm2Hh8l6WPTIAIEMFhQ), 「200万销量、2000万玩家之后，AI游戏找到新方向了？」를 제작자가 확보한 원문 요약에 근거해 적용한다. 이 검토자는 원문 전체를 독립 재검증하지 않았다. 제목과 사례의 판매량·이용자 수는 **기사의 보고값이며 검증된 시장 측정치로 사용하지 않는다.**

| 사례의 관찰 | 이 게임에 맞는 적용 | 피할 것 |
|---|---|---|

## 세계관에 맞는 기능 경계

- 플레이어 문장은 **내 메모·미확정**이다. 새 단서, 기관의 공식 기록, 인물의 기억이나 사실이 되지 않는다.
- 읽을 수 있는 것은 이미 남은 관측과 연결 구조다. 얼굴·의도·대화·과거 장면을 복원하거나 빈칸을 사실로 채우지 않는다.
- 자료 두 개와 독립 매체 두 종을 구분한다. 같은 원본의 사본 둘은 하나의 원천이며, 연결 수만으로 결론의 타당성이 생기지 않는다.
- 검토 결과는 관찰 가능한 구조만 말한다. 예: `연결한 자료 2개 / 같은 원본에서 나온 자료가 포함되어 있습니다.` 확률·신뢰도 점수·정답 배지·확정 가능 배지는 표시하지 않는다.
- 문장은 그대로 보존하고 출처 선택은 별도로 처리한다. 글 속의 명령, 정답처럼 보이는 단어, 인물 이름이 기능 권한이나 질문 단계를 바꾸지 않는다.
- 검토 노트는 선택 기능이다. 빈 문장에 자료만 연결하거나, 아예 쓰지 않고도 기존 도구·힌트·완주 경로를 이용할 수 있다.

## 다음 검증 질문의 최소 규칙

[TARGET] 자유문장의 의미를 채점하지 않는다. 현재 열람 가능한 자료에서 플레이어가 선택한 출처들의 관계만으로 저작 질문 하나를 고른다. 같은 입력·같은 공개 상태에는 같은 질문을 유지하고, 타이핑마다 새 반응을 만들지 않는다.

| 연결 상태 | 구조 요약 | 다음 질문 예시 |
|---|---|---|
| 출처 없음 | 아직 연결한 자료가 없음 | `이 생각은 직접 본 어떤 관측에서 시작됐나요?` |
| 같은 원본의 복제만 연결 | 여러 자료가 같은 원천에서 나옴 | `연결한 기록들이 같은 원본에서 나온 것은 아닌가요?` |
| 독립 매체가 아직 부족 | 대조할 매체 관계가 제한적임 | `서로 다른 매체에서도 이 해석을 확인할 수 있나요?` |
| 독립 매체가 연결됨 | 대조할 출처가 연결됨 — 정답 판정 아님 | `이 해석과 맞지 않는 관측은 없었나요?` |

[TARGET] 숨겨진 자료명·위치·인물·시각·해답을 문장에 삽입하지 않는다. 사용자가 연결하지 않은 특정 단서를 권하는 기능도 첫 범위에서 제외한다. 해답을 요청했을 때는 기존 힌트 UI를 **사용자가 직접** 여는 경로를 유지한다. 검토 요청 횟수나 문장 길이가 기존 무료 힌트의 단계를 자동 승격하지 않는다.

## 오프라인 프리미엄·저장 일관성

[TARGET] 본 기능은 로컬에서 완결되고 계정·네트워크·추론 잔액을 요구하지 않는다. 무료 연습·무료 힌트·무제한 재시도 원칙을 유지한다. 초안을 보관하는 것은 플레이어가 택한 메모 저장이며, 연습 횟수·실패를 엔딩·평가·업적에 기록하는 일이 아니다. 원문과 연결을 다시 열 수 있어야 하며 검토 문구가 바뀌더라도 원문을 덮어쓰지 않는다.

[TARGET] 초안 보관/불러오기는 기존 확정 기록·체크포인트·준비 조건·이동 선택과 분리한다. 메모 작성이나 검토 질문 수신으로 확인 조건을 충족시키거나 저장 수락·진행 해금을 발생시키지 않는다. 본래의 프리뷰→확정 흐름은 기존 규칙이 계속 소유한다. 초안 복원 시 아직 공개되지 않은 출처는 제목/내용을 노출하지 않고 연결 불가 상태로 처리한다.

## 첫 적용에서 확인할 것

1. 빈 메모·자료만 연결·노트 미사용으로도 기존 플레이가 유지된다.
2. 같은 원본의 복제로 독립 근거 수가 늘어나거나 정답 배지가 생기지 않는다.
3. 잠긴 출처, 임의 출처 식별자, 다음 장 인물을 가설에 적어도 새 정보나 권한이 나오지 않는다.
4. 어떤 자유문장도 사실·확신도·정답으로 판정하지 않는다. 출력은 연결 구조와 저작 질문뿐이다.
5. 로컬 초안을 다시 열어도 원문·연결이 보존되며 공식 확정 상태는 변하지 않는다.
6. 키보드/마우스/컨트롤러, 한글 IME 조합 중 Enter, 질문 읽기 중 닫기/복귀가 의도한 초점을 유지한다.
7. 사람이 실제로 더 좋은 반증 질문을 떠올렸는지는 별도 플레이테스트로 본다. 정적 검증으로 몰입·이해·재미 향상을 주장하지 않는다.

# M27 · 실마리 명료화 — 계획과 인수 기준 (RFC-CX-M27-20260918)

사용자 지시(2026-09-18): "개선 방향은 게임의 클루가 명확하고 확장 가능한 시나리오 유지와 각 스테이지별 또는 실마리의 중간 지점이 명료해야 하고, 게임 진행이 가능하고 가이드나 튜토리얼이 포함되도록 플레이 관점에서 밸런스와 리소스 UI 개선."

근거 조사(읽기 전용 3건, 세션 내): 캠페인 데이터 지도 · 런타임 안내 지도 · 밸런스/리소스 UI 감사. 핵심 발견 — (1) 사건 흐름 카드의 진행 카운터가 **비트와 무관하게 t0-b3의 인용 2건에 고정**되어 인수·회로 단계에서 "필요한 인용 0/2"와 판독 단계 지시문을 보여 준다(`T0GameSession.cs:245-250`); (2) 비트 내부 중간 지점(요구조건)이 데이터에 라벨·순서 없이 존재하고 화면 어디에도 목록으로 나오지 않는다 — 특히 t0-b3에서 인용 2/2인데 결손 구간 끝점이 틀린 경우 무엇이 열려 있는지 어떤 표면도 말하지 않는다; (3) 결손 구간 "끝"의 정의가 데이터(마지막 결손 눈금 H+2:56)와 술어(첫 복구 눈금 H+3:00) 사이에서 모호하다; (4) t0-b1 목표문이 비행동문("오늘 밤, 무엇이 남을지는 아직 정해지지 않았다.")이고 t0-b2 목표문에 내부 규칙 번호("법1")가 있다; (5) C1 안내 절은 자리표시 문구이고 C1 카드 문구는 미번역 리터럴이다; (6) 진행 표시는 전부 텍스트뿐이며, 힌트 제안 토스트에는 형태 단서가 없고 끌 수 없다(C6-F35).

## 조사 질문 · 세 축 모두 완료

### A. 주요 규칙과 플레이어 신뢰

이 프로젝트에 필요한 규칙을 **정보/인식, 조작, 판정, 실패·회복, 확정·저장, 선택의 결과, 접근성**으로 정리한다. 기존 규칙 중 유지할 것/충돌할 것/플레이어에게 충분히 보이지 않는 것을 구분한다. 비처벌적 연습과 되돌림이 있어도 추리의 긴장·책임·발견이 성립하는 메커니즘을 근거로 설명한다. 결과 미리보기와 과도한 정답 안내의 경계, 출처 독립성의 이해 가능성, 필수 단서 자동 보존과 추론 대행의 차이를 다룬다.

### B. 코어 루프와 첫 플레이 검증

초 단위 조작 루프 → 한 추론의 사건 루프 → 장 진행/재방문 루프를 연결한다. 각 단계에 플레이어 질문, 실제 동사, 관찰 가능한 피드백, 새로 얻는 정보, 선택/비용, 다음 동기를 넣는다. 메뉴 클릭/체크리스트가 추론을 대신하는 위험을 현재 T0와 대조한다. 첫 60초·첫 사건·20–30분 슬라이스에 대해 구체적인 수정안과 반증 가능한 검증 기준을 제시하되 시간을 실측처럼 쓰거나 480분 채우기로 우회하지 않는다.

### C. 상세 게임 구성과 생산 우선순위

튜토리얼, 퍼즐 학습/변주/결합, 단서 배치와 의존 그래프, 구역 상태 변화, NPC/대화/세 결말, 도구별 손 조작·피드백, UI/증거함/가설판, 사운드·연출, 저장/재진입, 접근성, 콘텐츠 저작·검증, 사람 플레이 관찰을 포함한다. 단순 기능 목록 대신 **어떤 반복 행동이 어떤 경험을 만들며 어느 비트/구역에 배치되는지** 보여준다. 완성된 기술과 아직 가설/초안인 부분을 구분하고, Base production gate 이전/이후 작업을 분리한다.

## 외부 근거와 비교 대상

- 기존 조사와 중복 요약만 하지 않는다. Return of the Obra Dinn, Papers, Please, The Roottrees are Dead, The Room, Myst를 출발점으로 삼고, 지식 기반 진행/퍼즐 학습 근거가 필요하면 Outer Wilds 또는 The Case of the Golden Idol을 추가한다. 모든 게임을 실제로 플레이했다고 주장하지 않는다.
- 개발자 원문·포스트모템·공식 설계 발표/인터뷰·공식 접근성 지침을 우선한다. 상점 설명은 기능 약속의 근거일 뿐 재미·매출·인과 효과의 증거가 아니다. 검색 결과만 읽은 자료와 본문을 직접 확인한 자료를 구분한다.
- 중요한 권고는 원문 URL, 제목, 게시 시점(확인될 때), 열람일, 뒷받침하는 좁은 주장과 우리 프로젝트 적용/비적용 이유를 연결한다. 비공개/유료/확인 불가 내용과 의견은 명시한다. 오래된 설계 원문도 유효하며 최근 동향은 2026-09-13 현재 확인 가능한 것만 쓴다.
- 다른 게임의 타이머·페널티·IP/캐릭터·서사·고유 퍼즐을 그대로 이식하지 않는다. 원리 수준의 차용과 차이를 설명한다.

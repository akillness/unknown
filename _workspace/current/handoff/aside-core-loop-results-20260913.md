### 외부 원문 교차 확인

Main은 보고서 E2/E4/E9/E10/E11/E12의 관련 원문 주장과 별도 튜토리얼 상세 지침을 직접 확인했다. 나머지 외부 자료는 Aside의 원문 조사 범위를 따른다.

- [Papers, Please 휴대폰 이식 개발기](https://dukope.com/devlogs/papers-please/mobile/): 문서 가독성/배치의 충돌, 사용자가 고정한 문서와 검사 중 선택 정보의 지속 표시. **우리의 적용은 비교 정보 보존이며 모바일 캐러셀이나 벌금 복제가 아니다.**
- [Golden Idol 개발자 인터뷰](https://www.gamedeveloper.com/design/case-of-the-golden-idol): 개별 정답 피드백의 대입 위험, 전체 오답 판정만 줄 때의 좌절, 정답을 모르는 사람의 검증 필요. 우리 게임의 효과를 보장하는 실험은 아니다.
- [Outer Wilds 개발자 인터뷰](https://www.gamedeveloper.com/design/road-to-the-igf-alex-beachum-s-i-outer-wilds-i-): 배운 지식으로 다음 탐색과 같은 장소의 해석을 바꾸는 설계. 시간 루프·사망·산소 제한을 이식하지 않는다. 상용 출시 전인 2015년 설계 기록이다.
- [Microsoft XAG 115](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/115): 중요한 파괴적 행동의 검토/확인/되돌림, 홀드 외 대안. 작은 조작마다 확인창을 추가하는 근거로 확대하지 않는다.

## 유지할 규칙

[CARRIED] 아래는 새 규칙이 아니라 현재 프로젝트의 보존 경계다.

1. 기록이 없다는 것과 사건이 없다는 것을 구별한다. 계통 밖·오차띠 겹침은 보류할 수 있다.
2. 독립 근거는 **다른 매체 AND 다른 원본 계보**다. 사본·OCR·낭독은 새 출처가 아니다. 이것은 게임의 판정 규칙이지 보편 인식론이 아니다.
3. 연습·되돌림·힌트는 무료이며 필수 단서는 보존한다. 부식예산은 구성 제약이지 소모 통화가 아니다.
4. 조작·시험 결과·내구 저장 성공을 구별한다. 확정 전 프리뷰와 복구, 한 입력 한 명령, 키보드 대체 경로를 지킨다.
5. 힌트와 실패 사유가 추론을 대신하지 않는다. 180초는 도움 제안 조건이지 도움 사용권의 대기시간이 아니다.
6. 선택은 현재 보호 상태·후일담·제출 관점을 바꾼다. 과거 사실 변경, 세 벌의 캠페인, DLC로 완성되는 결말을 약속하지 않는다.

## 개발할 세 층 루프

[TARGET] **관측 → 한 조건 조작 → 예측과 결과 비교 → 복원/재시험 → 서로 다른 자료의 근거 고정 → 남은 질문 → 새 관점으로 재방문.**

- **조작 루프:** 선택 위치/구성 변화가 선·곡선·집게·문자 피드백에 대응한다. 입력 횟수나 애니메이션 재생을 추론 성공으로 세지 않는다.
- **사건 루프:** 플레이어가 두 자료와 범위를 선택해 관계를 설명한다. 무엇을 확정했고 무엇은 아직 모르는지 분리한다. 자유 메모나 철자 채점을 필수 진행 조건으로 넣지 않는다.
- **장 루프:** 같은 구역에서 ‘처음 질문 → 바뀐 조건 → 다시 확인할 질문’을 저작한다. 같은 길을 걷는 시간은 신규 콘텐츠가 아니다.

T0는 인수 → 회로 범위 → 판독/대조 → 인용의 기존 세 비트로 첫 검증 범위를 고정한다. **25분은 설계 목표**다. C1의 두 비트를 더한 시간을 20–30분 T0 슬라이스라고 부르지 않는다. Aside의 ‘정전이라면 왜 대장이 남았는가’ 같은 후속 질문 문구는 새 저작 후보이며, 실제 사용 전 worldview/synopsis가 T0 공개 상한과 대조해야 한다. 이 보고서가 문구를 승인하지 않는다.

## 승인된 이미지 연결

**인트로 배경:** `assets/generated/2d/concept/intro-m5-r03/image.png`, SHA256 `24a2e45c733fba2a43bffd602906358191479f47e183355001de36c691d7a5e2`. 무지 남색 장부·문자 없는 전화 다이얼·빈 트레이·어두운 우측 여백. C1 판독기/서명지를 인트로에 넣지 않는다. 수평선 약 y25%는 스타일 목표38–44%와의 구도 편차로 보존한다. 이 원본은 영상 이전에 생성됐고 영상 이후 재생성됐다고 부르지 않는다.

**C1 방향표 표면:** `assets/generated/2d/ui/m5-direction-surface-r01/image.png`, 실제 **1254×1254**, SHA256 `52c4b3cc65cc1432bd94c5e7207ea35a50cbd5d8507f98e9c27f760db590b414`. 같은 폴더 `reference-frame.png`는 C1 실제 영상 **2.5초**에서 추출, SHA256 `b34fa327235ddb7a5eeae3ad15d9a575976cf45aef4de9f4519e618cec3f52d3`. 정확한 실행 프롬프트는 같은 폴더 `prompt.txt`다. 원본 프레임/GTI 출력/실행 영수증의 실제 출처를 유지한다.

[OBSERVED · 직접 시각 검수] 새 표면은 청흑/심해 잉크의 낮은 대비 면이며 중앙은 조용하고 테두리에 미세 마모가 있다. 문자·숫자·단서·기계·종이·미해결 마스크 형상은 보이지 않는다. 방향표 장식의 내부 프로토타입 후보로 **시각 통과**. 원본 영상의 조절부를 복사한 UI 아이콘이 아니라 GTI가 재생성한 중립 표면이다.

## 네이티브 연출 계약

- 인트로는 hub r03 **한 장**과 정적 캡션 2단계다. 첫 **3125 ms**, 다음 **2875 ms**, 합계 **6000 ms**. 3125 ms는 실제 영상 컷에서 채택했다. 실제 영상 길이6041.667 ms와 네이티브 총시간은 구별한다.
- 첫 표시부터 설정과 건너뛰기/시작이 가능하다. 저감모션은 같은 정보와 즉시 명시적 시작을 제공한다. 재개에 인트로를 강제하지 않는다.
- C1의 관찰/시험/기록 방향표만 새 금속 표면을 사용한다. 실제 선택·공개된 시험 결과·후보/저장 대기/실패/수락 상태만 읽는다. 색/질감/영상 타이밍으로 상태를 만들지 않는다.
- 150% 문자 대비, 배경 위 초점 표시, 키보드/포인터 일치, 입력 소비, 저장·시뮬레이션 불변성은 **실제 네이티브 인수 대기**다.

## 기각한 리소스와 공개 경계

인트로 영상 후반에 생긴 줄무늬 종이·다이얼 표시, C1 영상 후반의 자동 세척/하단 가림 제거, 확대 구도 이동은 기각한다. 생성 소금 그릇·병·핀셋·육각 트레이는 게임 도구/염판 매체로 승격하지 않는다. 미해결 마스크는 기존 시스템의 승인 좌표를 유지한다.

[TARGET] 두 실제 이미지의 시각 적합성은 내부 프로토타입 검수다. 제공자 경로 지원 여부, 산출물 소유권, 상업 배포 권리는 별도 검토이며 여기서 승인하지 않는다. 이미지/영상 provenance는 디렉터가 승격하기 전 상태를 유지한다. 생성 영상은 한계가 기록된 프리비즈이며 실제 게임플레이로 배포하지 않는다.

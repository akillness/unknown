# 시스템 스펙 — hint-system (무료 3단계 힌트, 진행 불가 0 보증의 마지막 층)

전부 `[TARGET]`. 실제 사용률·이탈률 실측 0건. 힌트는 **G7 대체 검증(퍼즐 도달성)** 의 핵심 장치이며 상품 가치(유료 힌트)와 무관하다.

| 항목 | 값 |
|---|---|
| 단계 | 정확히 3단 (33/33 비트가 3개 힌트를 가짐) [OBSERVED: campaign.meta.md §4] |
| 비용 | 0. 횟수 제한 0. 업적 페널티 0 [OBSERVED: balance/puzzle-balance.md] |
| 무진전 감지 | **180초**. **강제 아님**, "도움 보기" 제안 1종만 |
| 자동 제안 모델 | **180초 단일 제안 + 무시 시 180초 쿨다운**. 단계 자동 승격 없음 (RFC-P3-015) |
| 저장 | 사용 기록은 세이브에 남되 **엔딩·보상·평가에 영향 0** |

## 1. 입력

| 입력 | KB/마우스 | 패드 | 결과 |
|---|---|---|---|
| 힌트 열기 | `F1` | `LB`+`RS` | `OpenHint(beatId)` |
| 다음 단계 | 클릭 | `A` | `RevealHint(level+1)` — 순서대로만 |
| 닫기 | `Esc` | `B` | 상태 보존 |
| 제안 무시 | 토스트 닫기 | `B` | `hintOfferDismissed += 1`, 재제안은 **180초 쿨다운 후**. 재제안 내용은 매번 동일한 1종이다 |

## 1-A. 키보드 파생 `[C4-F21]`

**신설 2026-09-10 R6 (C6/C7).** §1 표에서 KB/마우스 열이 포인터 조작만 적은 행의 키보드 단독 경로다. 규칙 id 는 `systems/interaction-rules.md` §1-3.4(D-1~D-7)를 인용한다. §0-8(키보드 단독 완결)이 전역 보장이고, 이 표는 그 보장이 **행 단위로** 어떻게 성립하는지를 적는다.

| 위 표의 행 | 파생 규칙 | 키보드 단독 경로 |
|---|---|---|
| 다음 단계 (클릭) | **D-1** | 「다음 단계」 버튼에 초점 후 `Enter`. 단계는 순서대로만 열린다(H-R9) |
| 제안 무시 (토스트 닫기) | **D-1** | 토스트에 초점(`Tab`) 후 `Enter`, 또는 `Esc` 로 닫기 — 둘 다 `hintOfferDismissed += 1` |
| 힌트 열기 · 닫기 | — | 이미 키보드 경로다(`F1` · `Esc`) |

- 토스트는 **초점을 빼앗지 않는다.** `Tab` 순회에 끼어들 뿐이며, 무시해도 진행이 막히지 않는다(비강제 · H-R9).

## 2. 상태기계

상태 변수: `currentBeatId`, `revealedLevel[beatId] ∈ {0,1,2,3}`, `idleSeconds`, `offerShown`.

| 현재 | 이벤트 | 다음 | 부작용 |
|---|---|---|---|
| `Closed` | `OpenHint` | `Level0` | 패널 열기, 현재 단계 표시 |
| `Level0` | `RevealHint(1)` | `Level1` | 1단 텍스트, `revealedLevel = 1` |
| `Level1` | `RevealHint(2)` | `Level2` | 2단 텍스트 |
| `Level2` | `RevealHint(3)` | `Level3` | **명확한 경고 후** 해답 표시 |
| `LevelN` | `Close` | `Closed` | 상태 보존 |
| `Closed` | `idleSeconds ≥ 180` (유효 조작 없음) | `Offered` | 비강제 토스트 "도움 보기" |
| `Offered` | 유효 조작 발생 | `Closed` | 토스트 자동 소멸, `idleSeconds = 0` |
| `Offered` | `Dismiss` | `Closed` | 다음 제안까지 180초 쿨다운. **`revealedLevel`은 변하지 않는다** |
| any | `BeatChanged` | `Closed` | 단계는 비트별로 독립 유지 |

**중요**: `idleSeconds`는 *입력 없음*을 세지, *생각 중*을 실패로 세지 않는다. 60초 이상 무입력 구간은 `afk_gap` **후보**로 텔레메트리에 별도 기록되며, 자리비움 여부는 회고로만 판별한다 (`ops/telemetry-contract.md` §5 AF7) — **자동 제외하지 않는다**.

**단계 자동 승격 없음 [RFC-P3-015 (F20)]**: 이 상태기계에는 `Offered → Level1` 전이도, 누적 시간·오확정 횟수로 `revealedLevel`을 올리는 전이도 **없다**. 자동으로 일어나는 일은 `Closed → Offered` 하나뿐이며 그것도 토스트 노출까지다. 1·2·3단은 **플레이어가 `RevealHint`로 순서대로 연다**. 따라서 "T1 180초 / T2 누적 420초 + 오확정 2회 / T3 누적 900초 + 오확정 4회"식의 3단 자동 승격 모델은 이 스펙에 존재하지 않으며, `balance/balance-sheet.md` §6의 해당 표는 폐기됐다(RFC-P3-015). balance가 소유하는 것은 **제안 임계 180초와 쿨다운 180초 두 개의 숫자**이지 승격 규칙이 아니다.

## 3. 규칙

| id | 규칙 |
|---|---|
| H-R1 | 단계 의미 고정: 1 = **방향**(무엇을 결정해야 하는가·어느 구역/도구), 2 = **절차**(필요한 매체 2종의 종류와 도구 순서), 3 = **해답**(정확한 자료·조작 값·성립 이유) |
| H-R2 | 1단은 어떤 자료인지 말하지 않는다. 2단은 정답 값·정답 대상을 말하지 않는다. 3단은 **이후 장의 진실을 말하지 않는다** |
| H-R3 | 단계는 순서대로만 열린다. 3단 직행 없음(경고 후 3단 열기는 2단을 거친 뒤) |
| H-R4 | 힌트는 **소각·붕괴된 자료를 되돌려주지 않는다**. 되돌릴 필요가 없도록 매체 2경로 불변식이 앞에서 보장한다 |
| H-R5 | 힌트 텍스트는 로컬라이제이션 키로만 존재한다. 코드·아트에 문자열을 굽지 않는다 |
| H-R6 | 힌트는 데이터다. 코드가 힌트 문장을 생성하지 않는다(절차적 생성 금지) |
| H-R7 | 3단 사용 후에도 업적·엔딩·후일담이 달라지지 않는다. 세이브의 `hintLevelUsed`는 텔레메트리·복구용이다 |
| H-R8 | 접근성 설정에서 "항상 1단 표시"를 켤 수 있다. 이때도 페널티 0. 이것은 **플레이어가 켠 설정**이지 시스템의 자동 승격이 아니다 |
| H-R9 | **자동 승격 금지 (RFC-P3-015)**: 어떤 경과 시간·오확정 횟수·실패 횟수도 `revealedLevel`을 스스로 올리지 못한다. 시스템이 자동으로 하는 것은 180초 무진전 시 비강제 토스트 1회 노출뿐이며, 무시되면 180초 쿨다운 후 같은 토스트를 다시 낸다 |
| H-R10 | 제안 임계(180초)와 쿨다운(180초)은 `[tunable: balance]` 한 쌍이다. 두 값을 바꿔도 **단계 수·승격 여부는 바뀌지 않는다** — 데이터로 승격 모델을 되살릴 수 없다 |

## 4. 실패 모드

| id | 상황 | 시스템 반응 | 플레이어 손실 |
|---|---|---|---|
| H-F1 | 3단까지 봐도 막힘 | **진행 불가로 판정**하고 로그에 `stuck_after_l3` 기록 + 구조 경로(체크포인트 이동) 제시 | 없음. 이 이벤트 1건이라도 발생하면 G7 대체 검증 FAIL |
| H-F2 | 비트에 힌트 3개 미만 | **임포트 실패**(fail-closed) | 없음 |
| H-F3 | 힌트 텍스트가 다음 장 진실을 포함 | 문서 리뷰에서 차단(자동 검사는 불가, `[INFERENCE]`) | — |
| H-F4 | 로컬라이제이션 키 누락 | **임포트 실패** | 없음 |
| H-F5 | 무진전 제안이 반복 노출로 방해 | 180초 쿨다운 + 세션당 상한 [tunable: balance]. 상한 도달 후에는 제안이 멈출 뿐 **힌트 패널은 언제나 `F1`로 열린다** | 없음 |

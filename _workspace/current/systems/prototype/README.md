# 상호작용 검증 모형 (prototype) — 훈련용 작업대 1개

`_workspace/current/systems/interaction-rules.md` 의 확정 조건이 **서로 모순 없이 성립하는지**를
실행으로 확인하기 위한 작은 참조 모형이다. Node 순수 리듀서 1개 + 그 원문을 그대로 인라인한 단일 HTML.

## 이것이 아닌 것

- 게임이 아니다. Unity 프로젝트·씬·빌드·데모·세로 슬라이스와 무관하다. 빌드 0건.
- 퍼즐이 아니다. 콘텐츠 깊이·난이도·재미에 대해 아무것도 주장하지 않는다.
- 플레이 시간을 주장하지 않는다. 측정 표본 0건. `planning/campaign.json` 의 `observedMedianMinutes` 는 여전히 `null` 이다.
- 캠페인 전체의 진행 불가 문제가 해결됐다는 주장이 아니다. 이 모형은 **가상의 훈련용 작업대 1개**만 덮는다.
- 비용·수익 모형과 완전히 별개다. 이 폴더에는 금액이 하나도 없다.

## 무엇을 덮는가 (경계)

`planning/campaign.json` 의 **T0**(판독·배선 범위·결손 구간)과 **C3**(기준이 다른 대장·공통 피크 3개 정합·
오차띠 겹침 판정)에서 규칙 부분만 뽑아 하나의 가상 작업대로 압축했다. 서사·연출·대사·구역은 들어 있지 않다.

| 요소 | 수 | 내용 |
|---|---|---|
| 매체 | 5점 | 표준 염판 원본 / 같은 판의 복제 스캔(동일 출처) / 부두 염판(다른 출처·같은 종류) / 부두 조위대장 / 옥외 당직일지(배선 범위 밖) |
| 공통 피크 후보 | 4개 | 실제 대응 3개 + 거짓 대응 1개 |
| 사건 쌍 | 2쌍 | 간격 20분 / 간격 6분 |
| 경로 | 3개 | 저지대 우선 · 부두 우선 · 부두 급속 증설안(부식 12 > 한도 9) |
| 엔딩 관점 | 3종 | 기록 무결성 · 주민 청구 · 운영 연속성 |
| UI 단계 | 6개 | 판독 → 배선 범위 → 정합 → 선후 판정 → 프리뷰·확정 → 이중서명·제출 |

## 모형이 강제하는 규칙

1. **두 매체 독립**: 같은 출처의 사본은 세지 않고(`SAME_ORIGIN`), 같은 매체 종류도 세지 않는다(`SAME_MEDIUM`).
   유효한 근거 쌍은 5점 중 정확히 3쌍뿐이다.
2. **공통 피크 3개 + 잔차 ≤ 4분**: 피크가 2개면 잔차가 작아도 확정되지 않는다(`PEAK_COUNT_SHORT`).
   거짓 대응이 섞이면 잔차가 한도를 넘는다(`RESIDUAL_OVER`).
3. **선후 판정**: 관측소별 오차 4분 → 합 8분. 간격 20분은 `ordered`, 6분은 `unknown`.
   `unknown` 은 무사건이 아니며 이후 진행을 막지 않는다.
4. **프리뷰 → 확정**: 프리뷰 없이 확정은 막힌다(`NO_PREVIEW`). 경로를 바꾸면 프리뷰가 무효가 된다.
   부식예산 초과 구성은 확정 직전에 막힌다(`CORROSION_OVER`).
5. **자동 저장(메모리)**: 확정·서명 직전 상태를 메모리에만 보관한다. 디스크·네트워크 쓰기 없음.
6. **되돌림·초기화**는 판독 사본과 필수 단서를 **절대 지우지 않는다**.
7. **엔딩 3종**은 재산 보호 플래그(`null` / `lowland` / `dock`) 어느 값에서도 잠기지 않는다.
8. **차단은 예외를 던지지 않는다.** 항상 사유 코드 + 한국어 문장을 돌려주고 화면에 그대로 보여준다.

## 파일

| 파일 | 역할 |
|---|---|
| `model.mjs` | 순수 리듀서 · 파생 판정 · 세션(되돌림/자동저장/저장·불러오기) · 불변식 9개 · 유한 도달 상태 탐색. import 0개. |
| `test-model.mjs` | `node:assert/strict` 만 쓰는 검증기. 표적 테스트 + 전수 탐색. |
| `build-prototype.mjs` | `model.mjs` **원문 바이트를 그대로 인라인**해 단일 HTML 생성. 자체 검사 포함. |
| `README.md` | 이 문서. |
| `prototype.meta.md` | 실행 영수증·해시·정직성 경계. |

HTML 은 판정 로직을 새로 쓰지 않는다. 화면 계층은 `reduce` / `sessionApply` / `*Status` 를 호출만 한다.
따라서 **테스트가 통과한 규칙과 화면이 보여주는 규칙이 같은 코드**다.

## 실행

```bash
cd _workspace/current/systems/prototype
node test-model.mjs          # 검증 (약 40~45초, 전수 탐색 포함)
node build-prototype.mjs     # 단일 HTML 생성
node build-prototype.mjs --out ./interaction-prototype.html   # 출력 위치 변경
```

네트워크 접근 0회, 설치 0회, 계정 0개, git 조작 0회. Node 표준 라이브러리만 쓴다.

## 검증 방법

**표적 테스트** — 무효 분기마다 하나씩: 미판독 근거, 피크 부족, 잔차 초과, 정합 전 판정,
같은 출처 사본, 같은 매체 종류, 배선 범위 밖, 배선 미확인, 프리뷰 없는 확정, 부식 초과,
되돌림, 4종 취소, 초기화 단서 보존, 자동 저장 복구, 저장 왕복, 스키마 누락/상위/형식 오류, 체크섬 실패와 복구 3선택지.

**전수 탐색** — 초기 상태에서 조작 알파벳 35개를 폭넓이 우선으로 전개해 도달 가능한 모든 상태를
남김없이 열거하고, 각 상태에서 불변식 9개를 검사한다. 큐가 비어야 통과이며 잘림은 실패로 처리한다.

탐색의 명시적 경계: 되돌림·초기화·저장/불러오기는 **새로운 코어 상태를 만들지 않으므로**
(이미 도달한 상태로만 돌아간다) 탐색 알파벳에서 빼고 표적 테스트로 따로 덮는다.
오프셋은 연속값이지만 탐색에서는 대표값 4개 + 자동 맞춤 결과만 전개한다.
리듀서 자체는 `-45~45` 범위의 모든 정수를 받는다.

## HTML 산출물

- 단일 파일 자기완결. CDN·폰트·이미지·`fetch`·`XMLHttpRequest`·`WebSocket` 0건 (생성 시 자체 검사).
- 다크 + 시폼, 한국어. 대화상자 없음, 자동 재생 없음, 애니메이션 없음.
- 상시 배너: `상호작용 검증 모형 · Unity 빌드 아님 · 플레이시간 미측정` (sticky, 제거 불가).
- 모든 상태는 **문자 라벨이 먼저**다. 색은 보조이며 배지에 `●` `▲` `◆` `○` 기호가 함께 붙는다.
- 키보드: `Tab` 이동, 경로·관점 라디오 그룹은 방향키 순회, 오프셋 슬라이더는 방향키 1분 단위,
  `Enter`/`Space` 실행. 버튼을 비활성화하지 않고 **눌렀을 때 차단 사유를 문장으로 표시**한다.
- 차단 사유는 각 단계 안에 "확정할 수 없는 이유 / 서명할 수 없는 이유"로 상시 노출되고,
  상단 `role="status"` 영역에도 읽힌다.

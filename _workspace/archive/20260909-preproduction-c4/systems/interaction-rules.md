# 상호작용 규칙 — C4 (도구 6종 · 확정 조건 · 힌트 · 복구)

전부 `[TARGET]` 설계다. 플레이·성능 실측 0건. 여기서 정의하는 것은 **입력 → 보이는 반응 → 확정 조건**의 계약이며, 연출 품질이나 재미의 증거가 아니다.

## 0. 전역 불변식
1. **전역 실시간 타이머 없음.** 밤 21:00~05:00은 장 완료로 진행하는 이야기 위상이다. 읽는 속도로 벌하지 않는다.
2. **연습·되돌림 무제한, 무료.** 실패는 자원·진행·접근 권한을 빼앗지 않는다.
3. **필수 단서는 첫 판독 시 자동 보존**(`autoKeptClueIds`)되며 어떤 행동으로도 사라지지 않는다.
4. **확정 전 항상 프리뷰**, 확정 순간 항상 체크포인트.
5. **재산 보호는 이진 플래그 1개**(`propertyProtection`). 후일담 텍스트 2쌍만 바꾸고 **필수 단서·엔딩 3종 접근성은 불변**.
6. **세 엔딩은 한 회차 안에서 재시작 없이 도달 가능**하다. 최종 제출 화면에서 관점을 바꿔 다시 확정할 수 있다.
7. 색·소리·움직임 **단독으로** 결정적 상태를 전달하지 않는다. 항상 문자 라벨이 함께 있다.

## 1. 입력 계약
| 행동 | KB/마우스 | 컨트롤러 |
|---|---|---|
| 시점 노드 이동 | 노드 클릭 / `Q` `E` 인접 순회 | 좌스틱 방향 + `A` |
| 대상 조사 | 좌클릭 | `A` |
| 도구 열기 | `Tab` 도구 휠 / `1`~`6` | `LB`/`RB` 순환, `Y` 휠 |
| 미세 조절 | 드래그, `Shift` 정밀, 휠 | 스틱, `LT` 정밀, D-Pad 1스텝 |
| 프리뷰 | `Space` | `X` |
| 확정 | `Enter` 길게 누름 0.4s | `A` 길게 누름 0.4s |
| 되돌림 / 다시 | `Ctrl+Z` / `Ctrl+Y` | `LB+X` / `LB+B` |
| 증거함 · 가설판 · 힌트 | `I` · `H` · `F1` | `back` 탭 전환 · `RS` |
| 뒤로/취소 | `Esc` | `B` |
- 확정만 **길게 누름**이다(오확정 방지). 되돌림 가능한 조작은 전부 짧게 누름.
- 모든 바인딩은 재매핑 가능하고, 마지막 사용 장치에 따라 프롬프트 글리프가 즉시 바뀐다.

## 2. 도구 6종

### 2.1 circuit — 회로 지도
- **입력**: 구역 평면에서 계통 선을 따라가며 센서 노드 선택, `Shift` 다중 선택으로 범위 비교.
- **보이는 반응**: 선택 계통이 강조되고 **센서 범위 밖 영역이 사선 해칭 + "미배선" 라벨**로 표시된다. 사건 후보를 올리면 "이 사건은 배선 범위 밖" 배지가 즉시 붙는다.
- **확정 조건**: 없음(판독 도구). 대신 다른 도구의 확정에서 **배선 범위 밖 근거는 자동으로 무효 처리**되고 사유가 표시된다.

### 2.2 reader — 판독기
- **입력**: 염판/일지/대장을 판독대에 올리고 시간 범위를 드래그, 휠로 배율.
- **보이는 반응**: 첫 판독 시 **"검증 사본 보존됨" 토스트 + 증거함 항목 생성**. 이후 재생은 사본이며 원본 상태 게이지는 변하지 않는다. 분해능 4분 눈금이 항상 보인다.
- **확정 조건**: 판독 자체는 확정이 아니다. 판독 결과를 가설판에 **인용으로 고정**할 때만 출처(매체·계통·관측소)가 기록된다.

### 2.3 alignment — 조위정합
- **입력**: 두 자료의 조위 곡선을 겹치고 **공통 피크 3개를 각각 지정**. 스틱/드래그로 오프셋 조절, D-Pad는 1분 스텝.
- **보이는 반응**: 상단에 **원시 오차 ±40분 → 정합 후 잔차 ±N분**이 실시간 갱신된다. 잔차가 4분을 넘으면 막대가 회색 + "잔차 초과" 라벨.
- **확정 조건**: 피크 3개 지정 + **잔차 절댓값이 4분 이하**일 때만 "기준선 확정" 활성화. 미달이면 비활성 사유가 문장으로 표시되고 재정합은 무제한이다.
- **사건 선후 판정**: 두 사건 간격이 **두 관측소 오차폭 합(4+4=8분)보다 클 때만** 순서를 확정한다. 20분 간격 사건은 정합 후 확정 가능(20 > 8). 겹치면 판정은 `indeterminate`로 남고, 그 상태로도 진행은 막히지 않는다.

### 2.4 routing — 경로 구성
- **입력**: 밸브·수문·양수 경로를 노드에 연결. 드래그로 배선, 우클릭/`X`로 해제.
- **보이는 반응**: 구성이 바뀔 때마다 **통수 방향 화살표와 예상 수위 막대**가 갱신되고, 규칙 위반 구간은 붉은 점선 + 위반 이름.
- **확정 조건**: 위반 0건 + 부식예산 한도 내 + 프리뷰 확인. 확정하면 구역 상태가 실제로 바뀌고 체크포인트가 생긴다.

### 2.5 corrosion — 부식예산
- **입력**: 구성안을 가상 시험대에 올리고 시험 실행(무제한, 무료).
- **보이는 반응**: 구성 총 부식 비용 / 한도 게이지, 초과 시 **초과분과 원인 부품 목록**. 부식은 **정보이자 제약이며 채집·구매 재화가 아니다**.
- **확정 조건**: 한도 이내에서만 `routing` 확정이 열린다. 초과는 확정 전에 막히고 사유가 보인다. 막다른 구성은 **무료 우회관 1회**로 언제나 복구되며 영구 도구 상실은 없다.

### 2.6 seal — 이중서명
- **입력**: 결론 카드에 근거 슬롯 2개를 채우고 검증자 확인 → 주인공 서명.
- **보이는 반응**: 슬롯마다 **매체 종류 뱃지**(염판/일지/대장)와 출처가 보인다. 같은 종류가 두 번 들어가면 두 번째 슬롯이 즉시 회색 + "독립 매체 2종 필요".
- **확정 조건**: **서로 다른 매체 2종**의 근거가 있고, 각 근거가 배선 범위 안이며, 시간 근거는 정합 후 잔차 4분 이하일 때만 서명 활성화.

## 3. 출처 독립성 규칙
- 독립은 **매체 종류가 다를 때** 성립한다. 염판 원본, 그 표면 부식, 복제 스캔은 **모두 같은 출처 1개**로 센다.
- 필수 확정마다 겹치지 않는 매체 경로가 2개 이상 존재하고, 그중 **1개는 어떤 플레이어 행동으로도 파괴되지 않는다**(임포트 시 그래프 검증으로 강제).
- 단일 매체도 단서로 표시되지만 확정 슬롯은 채우지 못하며, 이유가 항상 문장으로 붙는다.

## 4. 힌트 3단계 (무료·무제한·되돌림 가능)
| 단계 | 이름 | 주는 것 | 주지 않는 것 |
|---|---|---|---|
| 1 | 방향 | 지금 무엇을 결정해야 하는지, 어느 구역/도구가 관련 있는지 | 어떤 자료인지 |
| 2 | 절차 | 필요한 매체 2종의 **종류**와 사용할 도구 순서 | 정답 값·정답 대상 |
| 3 | 해답 | 정확한 자료와 조작 값, 그 판단이 성립하는 이유 | 이후 장의 진실 |
- 단계는 순서대로만 열리고, 사용 기록은 세이브에 남되 **엔딩·보상·평가에 어떤 영향도 주지 않는다**.
- 힌트는 소각된 자료를 되돌려주지 않는다. 되돌릴 필요가 없도록 §3 불변식이 앞에서 보장한다.

## 5. 확정 → 결과 → 체크포인트
1. 프리뷰 패널: 바뀌는 것, 되돌릴 수 있는지, 영향 구역, 근거 2종 요약.
2. 길게 누름 확정 → 체크포인트 자동 생성(라벨: 장·일차·조위 위상).
3. 결과 요약 패널: 무엇이 바뀌었고 무엇이 보존되었는지. **필수 단서 보존은 명시적으로 다시 표기**한다.
4. 5장 제로섬 확정만 `propertyProtection`을 세팅한다. 확정 직전 체크포인트에서 선택 재시도 가능.

## 6. 저장·복구 흐름
- 자동 저장: 장 경계, 구역 이동, 모든 확정 직전.
- 수동 저장: 3슬롯 + 자동 1슬롯. 슬롯 카드에 장·일차·조위 위상·플레이 시간 표시.
- **손상 세이브**: 로드 시 체크섬 실패 → 복구 패널이 뜨고 `백업으로 열기 / 마지막 체크포인트 / 새로 시작` 3개만 제시한다. **손상 파일은 덮어쓰지 않는다.**
- 미등록 상위 스키마 세이브는 거부하고 파일을 그대로 둔다.

## 7. 엔딩·크레딧
- 최종 제출 화면에서 관점 3종을 **같은 회차에서 전환·재확정** 가능. 잠금·재시작 요구 없음.
- 엔딩 후 공통 종결 씬 1개 + 관점별 기록 패널 3개. 각 패널은 청문 결과, 4구역 최종 상태, 다음 근무 여부, 판 #0 처리를 명시한다.
- 크레딧은 언제든 건너뛰기 가능하며, 크레딧 후 마지막 체크포인트로 복귀해 다른 관점을 확정할 수 있다.

## 8. 한계
- 위 반응 시간·조작감·난이도는 전부 미측정이다. "즉시", "부드럽게" 같은 표현은 목표이지 관측이 아니다.
- 컨트롤러 매핑은 제안이며 실제 패드 테스트 0건이다.
- 도구 6종은 **기능 수**이며 별개 UI 프레임 6개를 만든다는 뜻이 아니다(공용 작업대 셸 1개 + 도구 패널 6종).

01 / CORE LOOP · NATIVE WINDOW

관찰하고, 옮기고, 되돌리기

판독기의 조위 곡선과 잔여 조건 표시를 읽고(관찰), 시작·끝 ±1 스텝으로 인용 시간창을 옮기고(조작), 갱신된 H−1:00 → H+5:56을 확인하고(확인), 툴바의 되돌림 · 다시로 상태를 되돌린 뒤 다시 적용합니다(되돌림). 이어서 자료를 매체명으로 교체해 기록국 조위대장을 다시 판독하고, 판독 → 검증 사본 보관 → 시간창 인용의 두 단을 그대로 통과합니다.

여기 보이는 슬라이스는 T0 t0-b3 구간의 판독·대조 구현입니다. 화면의 자료 이름이 내부 id가 아니라 당직실 표준판 · 기록판 / 기록국 조위대장 · 장부로 읽히는 것이 RFC-CX-015의 D-M9-17 수리입니다.

02 / GAMEPLAY · CHRONOLOGICAL

당직 인수에서 인용까지

같은 세션의 세 테이크를 시간순으로 이었습니다. 셸에서 M5 오프닝 2샷과 모토 문장이 지나가고, 당직실에서 인수 각서와 이관 목록을 열람해 판 #0을 결정합니다. t0-b3에서 시간 눈금을 끌어 내려 결손 구간의 끝 H−1:00을 고르고, 판독기를 열어 표준판을 판독합니다. 마지막으로 자료를 교체해 조위대장을 판독하고 인용을 고정합니다.

보이는 구현 슬라이스: M5 오프닝 연출 · 당직 인수 절차(각서·이관 목록·상시 슬롯) · 시간 눈금 선택기 · 판독기 안내 헤더와 잔여 조건 표시 · 인용 시간창 스텝 조정 · 자료 선택/교체 · 되돌림/다시.

이 영상이 증명하는 것과 하지 않는 것

RFC-CX-015 · 네이티브 실동작 플레이테스트

  • 증명함
    빌드된 플레이어의 창 녹화입니다. Unity 6000.5.6f1 개발 빌드를 1280×800 창으로 띄우고 macOS screencapture로 그 창만 녹화했습니다. 생성 영상도 previz도 아니며, 화면에 더한 픽셀은 직접 쓴 한국어 자막 카드와 그 판뿐입니다.
  • 무음
    오디오 트랙이 없습니다. 원본 녹화가 무음이고 이번 회차에 새 사운드를 만들지 않았습니다. 자막은 전부 화면 텍스트이며, 음성·효과음은 한 곳도 쓰이지 않았습니다.
  • 입력
    포인터 조작 기록입니다. 합성 키 이벤트가 Unity Input System에 닿지 않아 조작은 cliclick 포인터로만 했습니다. 키보드·컨트롤러 동등성은 PlayMode 자동 검증이 담당합니다.
  • 발췌
    연속 입력 증거가 아니라 발췌입니다. 화면이 전혀 변하지 않는 구간(특히 시간 눈금 목록의 정지 구간)을 잘라내고 세 테이크를 단순 컷으로 이었습니다. 컷 지점은 모두 프레임을 뽑아 확인했습니다.
  • 미측정
    사람 플레이테스트는 하지 않았습니다(n=0). 재미·몰입·25분 예산은 이 영상으로 판단할 수 없습니다. 녹화가 가변 프레임레이트여서 24fps로 정규화했으므로 성능·프레임레이트 주장도 담기지 않습니다.
  • 미포함
    회로 지도 정렬(−1/+1)·앵커·구획·근거 단계는 이 세 테이크가 시작되기 전에 끝나 화면에 없습니다. 프리뷰(diff 문장 + 되돌림 고지) → 확정 화면도 이 테이크 안에는 없습니다. 두 항목의 통과 기록은 아래 영수증에 있습니다.
  • 그레이박스
    좌상단 3D 뷰포트는 플레이스홀더입니다. 회로 지도·판독기 노드는 아직 그레이박스이며(M7 프리팹 재구성 이월), 자막 카드는 이 그레이박스 위에만 올립니다. 헤더·사건 흐름·목록 패널·툴바 같은 실제 UI는 한 곳도 가리지 않습니다.

출처와 영수증

두 편은 실제 게임 화면입니다. 컨셉 필름(M7 · 컨셉에서)과 달리 생성 프레임이 섞이지 않았습니다. 원본 3개 테이크는 사본으로 보존했고, 크롭·정규화·인코딩 파라미터와 컷 목록, 각 파일의 sha256은 provenance와 편집 타임라인에 그대로 적혀 있습니다.

편집 관례(24fps · H.264 CRF 20 · ASS 오버레이 번인 · 6초 챕터 카드 + 마지막 8초 정리 카드)는 concept-first-m7을 그대로 따랐습니다. 다만 해상도는 창 캔버스와 1:1인 1280×800(16:10)으로 냈습니다. M7의 720은 16:9 소스 기준이므로, 여기서 720에 맞추면 UI를 잘라내거나 10% 축소해 검은 띠를 붙여야 했습니다. 축소도 패딩도 없이 크롭만 적용했습니다.
